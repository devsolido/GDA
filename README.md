# 📚 GDA - Gestão Digital Agregada v3.0

Sistema acadêmico pessoal com navegação por páginas.

## 🚀 Como usar
1. Abra o index.html no navegador
2. Ou use Live Server no VS Code

## 📂 Estrutura
- pages/ - Páginas separadas por funcionalidade
- js/ - Módulos JavaScript
- styles/ - CSS global

## 🔧 Tecnologias
- HTML5 + CSS3 + JavaScript
- Backendless (sincronização)
- localStorage (persistência)
